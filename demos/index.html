FAIRDOC integration demos

Five host apps, five ways to attach FAIRDOC document storage. Each one exercises every function, using only the user's O365 token and an optional group.

DEMO 1

Course site — drop-in widget

One script tag plus <fairdoc-widget>. The host passes the token and course group, and gets events back.
 DEMO 2

Lab notebook — headless SDK

A custom NotebookLM-style UI built directly on SDK calls, with FAIR metadata completeness scoring.
 DEMO 3

Advising portal — backend proxy

The token stays on the app server, which forwards calls to FAIRDOC and also uses the SDK server-side.
 DEMO 4

Research data ingest — CLI / script

Bulk upload with metadata sidecars from a terminal or scheduled job. Run npm run demo:cli.
 DEMO 5

Committee portal — iframe + postMessage

An embedded FAIRDOC-hosted UI from another origin. The host steers it and receives a live event feed.
