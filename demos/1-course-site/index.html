Demo 1 — Drop-in widget. This course site adds FAIRDOC with one script tag and one HTML element. It passes the signed-in user's O365 token and the course's Entra group id. Every tab in the panel below works: collections, upload with FAIR metadata, versions, metadata edit and JSON-LD, move, delete and restore, sharing, search, activity log and usage stats.
Integration code
<script type="module" src="http://localhost:4000/widget/fairdoc-widget.js"></script>
<fairdoc-widget id="docs" api-base="http://localhost:4000"
                group="a1b2c3d4-0001-4000-8000-bio101000001"></fairdoc-widget>
<script>
  docs.getToken = () => msal.acquireTokenSilent(...).then(r => r.idToken);
  docs.start();
  docs.addEventListener('fairdoc:event', e => console.log(e.detail));
</script>
